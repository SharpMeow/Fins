# Real dimensions of what the game draws

The art standard (one scale, drawn from real dimensions) needs a size for every drawable, with a
source. This is that table, one row per object, keyed by the id the game uses for it. Nothing here
is estimated: every figure is quoted from the source named in its row, or is the midpoint of a
sourced range where the row says so. Rows marked with a note have a gap or a weaker source; check
those before a size depends on them. The game does not read this file; it is the reference that
sprite sizes and the scale constant are checked against.

Compiled 2026-09-22. Conversions use 1 in = 2.54 cm, 1 ft = 30.48 cm, rounded to 0.1 cm.

**How the numbers were gathered.** The network proxy blocked WebFetch for almost every authoritative domain (aqueon.com, fisheries.noaa.gov, fishbase.se, tropica.com, fluvalaquatics.com). Every figure below therefore comes from WebSearch results: the result URL plus the search engine's extract of that page. The quotes are that extract, not a direct read of the page. Spot-check any value that is load-bearing.

**"Size used."** This is a sourced figure, or the midpoint of a sourced range when the row says "midpoint". No value is estimated beyond that. W = width, D = depth, H = height, L = length, dia = diameter, TL = total length, SL = standard length.
